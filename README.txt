HOINet chapter reproducibility supplement

Unzip to one directory, then use that directory as the MATLAB working directory.
The archived feature profiles and pressure trajectories reproduce the classifier experiments directly.
Original study: run run_study_c_cascades.m (MATLAB R2025b, Statistics and Machine Learning Toolbox for the paired tests). The classifiers and Adam optimizer are implemented in MATLAB. Tables of archived run outcomes are under study_c_results.
Revision analyses: addpath(fullfile(pwd,'review_revision_analysis')); run_reviewer_checks; seedmatched_pair. These scripts use the same processed inputs. Mode names and all seeds are in the drivers. Model indices are 1 original pairwise, 2 redrawn shuffle, 3 HOINet, 4 pairwise with membership, 5 dependency-only pairwise with membership, 6 common inputs only. seedmatch.csv uses the original pairwise inputs with HOINet initialization/subsampling seeds.
map_checks additionally needs MATPOWER 8 on the MATLAB path. Set MATPOWER_ROOT to its installation folder. For hydraulic reconstruction set EPANET_MATLAB_TOOLKIT to the installed epanet_matlab_toolkit folder (version 2.2.6.1). Obtain Net3.inp from the EPANET Example Network 3 distribution and case33bw.m from MATPOWER, and place them in benchmark_data before rebuilding. No third-party simulator or installation is bundled.
Regeneration order: prepare_benchmark_data.py, prepare_physical_benchmarks.m, prepare_study_c_hydraulics.m, run_study_c_cascades.m. Run the optional map_checks and enforced_check separately. Do not put these scripts inside the MATLAB installation.
EV data source: City of Boulder Electric Vehicle Charging Station Data, https://services.arcgis.com/ePKBjXrBZ2vEEgWd/arcgis/rest/services/Electric_Vehicle_Charging_Station_Data/FeatureServer/0 . The archived extract matches Start_Date___Time LIKE '%2023%'. The supplied Python script pins the original single-format date parsing to reproduce the published 29,934-session subset; ISO-formatted timestamps are valid and were excluded by that original rule. Requires pandas and numpy. Processed inputs and raw source fields are included.
The original four pressure trajectories use closure commands with Net3 controls active. In enforced_check the failed pumps' own conflicting controls are removed and every solve is checked for closure. hydraulic_audit/codes.csv columns are condition (1 normal, 2 pump 10, 3 pump 335, 4 both), elapsed seconds, and hydraulic solve return code. status.csv contains 24 hourly rows and four condition columns for each of the two pumps.
signed_rank_all.csv is Supplementary Table S1. main.csv and seedmatch.csv each cover 20 runs. holdline.csv covers 26 folds. The other intervention CSVs contain five runs each, with 1 psi and original settings taken from the first five main runs. K1, K5 and K10 are separately validation-thresholded event F1 scores. Layer F1 is calculated over cascade records in that layer. For folds without positive assets in a layer the implementation returns zero, so use overall F1 when interpreting the line holdout.
